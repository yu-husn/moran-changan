# 墨染長安：一筆相思

給臺灣國中生的古風穿越戀愛與國文詞性網頁遊戲。

[開始遊戲](https://yu-husn.github.io/moran-changan/)

沈清霜在博物館導覽崔護〈題都城南莊〉時穿越到唐代長安，與顧懷瑾追查冤案，透過魯班巧鎖、辨詞投壺、曲水流觴、上元燈會及渾天儀推進故事。

- 博物館開場新增三位可愛國中學生（兩女一男），學生提問時呈現完整三人立繪。
- 40題詞性，每題2分，共80分。
- 5題115會考閱讀，每題2分，共10分。
- 五次對話二選一，彼此好感度最多10分，總分100分。
- 每題自動倒數20秒；答錯先給提示，補解不改首次分數。
- 支援手機、平板、筆電版面，以及觸控、滑鼠與鍵盤操作。
- 自動存檔、學習紀錄、錯題複習與教師章節展示。

## 使用

GitHub Pages從main分支根目錄發布，首頁會進入minigames/index.html。完整下載後也可直接開啟該檔案離線遊玩；請保留artwork-drafts/與minigames/assets/的相對位置。

存檔保存在目前瀏覽器與網站網域中；本機檔案版的進度不會自動轉移到GitHub Pages。
